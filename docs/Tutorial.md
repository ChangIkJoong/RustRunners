#  TUTORIAL : How to Play

## Main menu / navigation
- Navigate the Menu using your ``Mouse``. ``Click`` to **Enter**.
- ``Esc`` : Go back to the previous menu or exit to main menu.
## In-game movement
- ``W`` or ``Left Arrow`` : Move player left
- ``A`` or ``Right Arrow`` : Move player right
- ``Space or ``Up Arrow`` : Jump


- ``P`` : Pause / unpause the game
- ESC(mapped to TogglePauseCommand)
-  ``ESC`` : Go back to main menu.
